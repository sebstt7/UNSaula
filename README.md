Cronograma
    > organizacao de  sprints - exemplos, quantas sprints foram feitas, duracao de cada uma, listar e resunmir o que foi feito em cada sprint 

Riscos 
    > identificacao dos riscos - exemplo, tecnicos, de prazo, de equipe ous externos 
    > clasificacao probabilidade X impacto - exemplo, risco de atraso de uma tafera 
        probabilidade / impacto / priorodade 
       /////             ////      /////      (*TABELA*)
        alta             medio     alta 
    
    > estrategia de mitigacao, dizer o que fizemos para reduzir os riscos( reduzir atrasos)

Orcamento 
    >categorias de custos
        > mao de obra > horas de trablaho em equipe X valor/hora estimada
        > condigencia - reserva tipo 10 a 15% do totoal para imprevistos
        
    Ferramentas usadas (custo real ou hipotetico)

    Ferramenta	Custo	Observacao
    GitHub	Gratuito	Plano free suficiente pro projeto
    Trello	Gratuito	Plano free
    Hospedagem (ex: Vercel/Heroku)	Gratuito/R$ X	Se usaram algo pago

    escopo
        > mome e descricao geral do projeto
        > problema que o projeto resolve 
        > objetivos do prjeto
        > publico alvo 
        > funcionalidades incluidadas no escopo e fora do escopo 

Valor/impacto 
    > qual valor que a solucao entrega aos usuarios finais
    >Impactos sociais (quem e beneficiado, como)
    >Acessibilidade (a solucao pensa em usuarios com deficiencia? interface inclusiva?)]

ferramentas - Ferramentas utilizadas
