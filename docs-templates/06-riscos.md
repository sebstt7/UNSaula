# Riscos do Projeto

| Risco                                         | Possível consequência                                           |
| --------------------------------------------- | --------------------------------------------------------------- |
| Falta de tempo para desenvolver o aplicativo  | Algumas funcionalidades podem não ficar prontas até a entrega.  |
| Dificuldade da equipe com alguma tecnologia   | Pode atrasar o desenvolvimento de algumas partes do projeto.    |
| Problemas de comunicação entre os integrantes | Pode causar erros ou retrabalho.                                |
| Mudança de ideias durante o projeto           | Pode exigir alterações no planejamento e nas tarefas já feitas. |
| Falhas encontradas nos testes                 | O aplicativo pode apresentar problemas de funcionamento.        |

# Matriz de Riscos

| Risco                                         | Probabilidade | Impacto | Ação para reduzir o risco                                             |
| --------------------------------------------- | ------------- | ------- | --------------------------------------------------------------------- |
| Falta de tempo para desenvolver o aplicativo  | Alta          | Alta    | Organizar as tarefas e priorizar as funcionalidades mais importantes. |
| Dificuldade da equipe com alguma tecnologia   | Média         | Alta    | Pesquisar e buscar ajuda quando necessário.                           |
| Problemas de comunicação entre os integrantes | Média         | Média   | Realizar reuniões frequentes e manter contato pelo grupo.             |
| Mudança de ideias durante o projeto           | Média         | Média   | Definir bem os requisitos antes de iniciar cada etapa.                |
| Falhas encontradas nos testes                 | Baixa         | Alta    | Testar o aplicativo regularmente durante o desenvolvimento.           |

## Mitigações

- Organizar as tarefas da equipe e acompanhar o andamento do projeto.
- Priorizar as funcionalidades mais importantes do aplicativo.
- Fazer reuniões rápidas para alinhar o trabalho da equipe.
- Utilizar o GitHub para manter os arquivos organizados e atualizados.
- Realizar commits frequentes para evitar perda de trabalho.
- Pesquisar soluções e materiais de apoio quando surgirem dúvidas técnicas.
- Definir bem o escopo para evitar mudanças durante o desenvolvimento.
- Testar as funcionalidades conforme forem sendo desenvolvidas.
- Dividir as tarefas de forma equilibrada entre os integrantes.
- Acompanhar os prazos para evitar atrasos na entrega final.
